# 🔗 LinkLens

«Summarize any webpage from a single URL.»

LinkLens is an AI-powered URL summarizer that extracts the main content of a webpage and generates a concise, easy-to-read summary.

Simply paste a URL and let LinkLens do the reading for you.

---

✨ Features

- 🌐 Summarize any webpage
- 🤖 AI-generated summaries
- ⚡ Fast and simple interface
- 📄 Clean reading experience

---

🛠 Tech Stack

- Python
- Streamlit
- LangChain
- Groq

---

🚀 Getting Started

Clone the repository

git clone https://github.com/itslokeshx/LinkLens.git
cd LinkLens

Install dependencies

pip install -r requirements.txt

Run

streamlit run app.py

---

💡 How It Works

1. Paste a webpage URL.
2. LinkLens extracts the page content.
3. The AI reads the content.
4. A concise summary is generated.
